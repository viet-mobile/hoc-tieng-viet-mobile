# 한국어 모드 가사 단어 뜻 — 승인용 제안표 (2026-10-18)

이미 정해진 뜻(어휘 사전·기존 지정 74개)이 없는 가사 단어 976개 중, 가사 어순이 뒤바뀌었거나 음절 결합으로 사전에 나오는 말을 찾아 가사 문맥에 맞춰 고른 목록입니다. **승인 전이며 앱에는 아직 적용하지 않았습니다.**

- 사전: 네이버 베트남어 사전의 한국외국어대학교 지식출판원 「베트남어-한국어사전」(HUFS)과 문예림 「베트남어 입문 사전」. 위키낱말사전은 한국어 뜻이 없어 쓰지 않았습니다.
- 규칙: 단어 자체 → 사전에 없으면 두 음절은 앞뒤를 뒤집어, 한 음절은 앞뒤 음절과 결합(그대로·뒤집어)해 찾았습니다. 가사 어순대로 적은 칸이 앱에 들어갈 키이고, **음절이 더 많은 단어의 뜻이 항상 우선**합니다.
- 근거 칸: 「한국외대 사전」「문예림 입문사전」은 사전의 첫 뜻을 줄여 옮긴 것, 「어순 뒤집기」는 사전에는 반대 순서로 실린 것, 「수정·보충」은 사전 뜻이 가사와 맞지 않거나 사전에 뜻이 없어 제가 가사 문맥에 맞춰 고친 것, 「맥락 선택」은 사전의 여러 뜻 중 가사에 맞는 것을 제가 고른 것입니다.
