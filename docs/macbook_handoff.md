## 2. Setting up the Mac

- Node 20+, Python 3.12+ (`python3`), Google Chrome (`/Applications/Google Chrome.app`), `npm i -g wrangler` or `npx wrangler` (then `wrangler login`).
- The browser tests find their tools through `tests/helpers/platform.js`: `CHROME_PATH` and `PYTHON` override the defaults
  (`python3` on macOS / Linux). `scripts/preprod_verify.py` runs the Python steps with the interpreter that runs it:
  `python3 scripts/preprod_verify.py`.
- Line endings: the working tree is CRLF on Windows (`core.autocrlf=true`); on a Mac use `core.autocrlf=input`. `app_logic.js`,
  `template.html` etc. are LF in git.
- Nothing secret is in the repository: the Cloudflare login is per machine (`wrangler login`), `SF_PW` was only an
  environment variable (remove it: `Remove-Item Env:SF_PW`), `sf.sql` is deleted.
