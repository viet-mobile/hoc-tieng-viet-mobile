# 노래 단어 팝업의 한국어 뜻 보완

`lyric_meanings_ko.json`은 2026-10-18에 네이버 베트남어 사전의 표제어, 전체 뜻풀이, 한국어 대역어 및 예문을 확인하여 정리한 짧은 뜻이다. 각 항목의 `source`는 확인에 사용한 사전 페이지이다. 전체 사전이나 예문 본문을 배포하지 않고 팝업에 필요한 짧은 뜻만 빌드에 넣는다. 웹 사전을 실행 중 호출하지 않으므로 팝업에 네트워크 요청이나 대기 시간이 추가되지 않는다.

기존 어휘·발음 예제의 뜻이 비어 있을 때만 보완한다. 사용자가 지정한 가사 문맥의 뜻은 최우선이며, 클릭한 음절을 포함하는 기존 1~3음절 단어 중 긴 표현을 우선하는 규칙도 유지한다. 발음 변환 및 가사 원문은 수정하지 않는다.

다의어의 첫 번째 뜻을 자동으로 채택하지 않는다. 예를 들어 `mãi`는 ‘계속’, `lệ`는 ‘눈물’, `reo`는 ‘환호하다’, `quý`는 ‘귀중한’을 가사 문맥에 맞춰 선택했다. 확실한 뜻을 확인하지 못한 표기에는 뜻을 추측해 넣지 않았다.

빌드 후 아래 명령으로 단어 선택 규칙에 따른 전체 가사 빈칸을 다시 집계할 수 있다.

```sh
node scripts/audit_lyric_meanings.js
node scripts/audit_lyric_meanings.js --without-supplement
node tests/test_lyric_dictionary.js
```

`lyric_meanings_ko_audit.json`은 이번 데이터 기준의 집계 및 미보완 표기 목록이다. 남은 표기는 복합어의 일부 음절, 고유명사, 비베트남어, 오타 의심 표기 등을 포함한다. 이 목록에 있다는 이유만으로 가사를 자동 교정하거나 철자가 비슷한 다른 단어의 뜻을 연결해서는 안 된다. 다음 보완에서는 해당 표현 전체의 문맥과 출처를 확인한 뒤 사전에 추가하고 집계 파일을 갱신한다.
